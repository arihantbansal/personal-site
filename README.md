# arihantbansal.com

Static personal site built with Astro and Bun. HTML, Markdown, and agent-readable files are generated at build time from shared content.

```sh
bun install
bun run dev
```

Check types, formatting, and the production build:

```sh
bun run verify
```

The resume is not served from this site. It lives in the resume repository and is shared by link only.
